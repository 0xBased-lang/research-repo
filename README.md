## 🚀 Quick Start

### Option 1: Open Directly
Simply open `index.html` in any modern browser to view the website.

### Option 2: Local Server (Recommended)
```bash
# Using Python 3
python -m http.server 8000

# Using Node.js (http-server)
npx http-server

# Then open: http://localhost:8000
```

### Option 3: Live Server (VS Code)
1. Install "Live Server" extension in VS Code
2. Right-click `index.html` → "Open with Live Server"

## 🎨 Customization

### Colors
Edit CSS custom properties in `styles.css`:
```css
:root {
    --primary-500: #667eea;      /* Main brand color */
    --primary-600: #5a67d8;
    --primary-gradient: linear-gradient(135deg, #667eea 0%, #764ba2 100%);
    /* ... more variables */
}
```

### Content
1. **Company Info**: Update contact details in the Contact section
2. **Services**: Modify service cards in the Services section
3. **Projects**: Replace placeholder images in References section
4. **About**: Update company story in About section

### Images
Replace placeholder SVGs with actual photos:
- Hero section visuals
- Project reference images
- About section image
- Optimize images before adding (WebP recommended)

## 🚀 Deployment

### Option 1: Traditional Hosting
1. Upload files to your web server via FTP/SFTP
2. Ensure `index.html` is in the root directory
3. Configure SSL certificate (HTTPS)
4. Test all functionality

### Option 2: Netlify (Recommended)
```bash
# Install Netlify CLI
npm install -g netlify-cli

# Deploy
netlify deploy --prod
```

### Option 3: GitHub Pages
1. Push to GitHub repository
2. Enable GitHub Pages in repository settings
3. Select branch and root directory
4. Access via `https://yourusername.github.io/repo-name`

### Post-Deployment Checklist
- [ ] Test on multiple devices
- [ ] Verify contact form works
- [ ] Check all links
- [ ] Setup Google Analytics
- [ ] Submit sitemap to Google Search Console
- [ ] Test page speed with Lighthouse
- [ ] Verify SSL certificate (HTTPS)
