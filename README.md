## Current Projects

### SubScout - Intelligent Subscription Tracker Research

Comprehensive technical and business feasibility analysis for an AI-powered subscription tracking and cancellation service.

**Status**: Research Complete (November 2025)
**Verdict**: Feasible but capital-intensive, requires significant revisions from original pitch

#### Quick Links:
- **[Executive Summary](./EXECUTIVE_SUMMARY.md)** - Start here for decision framework
- **[Full Technical Research](./SUBSCOUT_TECHNICAL_RESEARCH.md)** - 50+ pages of detailed analysis
- **[Cost Calculator](./COST_CALCULATOR.md)** - Financial modeling and break-even analysis

#### Key Findings:
- ✅ Plaid integration works well (90%+ subscription detection accuracy)
- ❌ "One-tap cancellation" is not technically feasible (requires human concierge)
- ⚠️ Break-even requires 12,000-15,000 users (not 1,000 as originally projected)
- 💰 Capital requirement: $300-500K for 18-24 month runway
- 📊 Recommended pricing: $7.99-9.99/month (not $4.99)

#### Research Scope:
- Plaid API capabilities, pricing, and alternatives
- FTC Click to Cancel rule analysis
- Legal risks of automated cancellation
- Compliance requirements (PCI-DSS, SOC 2, GDPR/CCPA)
- Technical architecture recommendations
- ML/AI implementation for churn prediction
- 20-week MVP development roadmap
- Detailed financial modeling
