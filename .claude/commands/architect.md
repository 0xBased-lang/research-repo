# System Architecture Design

Design the system architecture for a new feature or project using the architect-agent.

## Task

$TASK

## Process

1. **Invoke Architect Agent**
   Use the architect-agent for this design task.

2. **Gather Requirements**
   - Functional requirements
   - Non-functional requirements (scale, performance, security)
   - Constraints (budget, timeline, existing systems)
   - Success criteria

3. **Research Current State**
   - Explore existing codebase
   - Identify current patterns
   - Find similar implementations
   - Document findings

4. **Design Architecture**
   - System components
   - Data flow
   - Technology stack recommendations
   - Integration points
   - Security considerations
   - Scalability approach

5. **Create Documentation**
   - Architecture diagrams (mermaid or ASCII)
   - Component descriptions
   - API contracts
   - Data schemas
   - Deployment architecture

6. **Evaluate Trade-offs**
   - Pros and cons of approach
   - Alternative solutions considered
   - Risks and mitigations
   - Cost implications

7. **Implementation Roadmap**
   - Break down into phases
   - Identify dependencies
   - Estimate complexity
   - Suggest team assignments

## Deliverables

- Architecture overview document
- Component diagrams
- Data flow diagrams
- Technology recommendations
- Implementation plan
- Risk assessment

The architect-agent will provide recommendations without implementing code.
